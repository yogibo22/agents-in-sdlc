**[GitHub Copilot cloud agent](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent)** permite que GitHub Copilot trabaje de forma asíncrona en la nube. Asignas trabajo en GitHub y el agente en la nube lo recoge en segundo plano: explora el repositorio, realiza cambios y abre una pull request, mientras tú puedes dedicarte a otras cosas.

A lo largo de estos ejercicios, añadirás instrucciones personalizadas que seguirá el agente en la nube y, después, asignarás una incidencia de GitHub para que implemente el trabajo. Revisarás y usarás agentes personalizados para dar forma a su enfoque, supervisar y orientar sesiones desde el panel de agentes y, por último, revisarás sus pull requests e iterarás sobre los resultados.

## Requisitos previos

Antes de participar en este taller, asegúrate de tener:

- [ ] Una cuenta de GitHub con un plan activo de **Copilot Student, Pro, Pro+, Business o Enterprise**
- [ ] El agente en la nube de Copilot habilitado para tu cuenta u organización

> [!TIP]
> ¿No tienes un plan de pago? Los estudiantes verificados pueden obtener GitHub Copilot gratis a través de [GitHub Education][callout-student-plan-education]. El plan **Copilot Student** incluye el agente, MCP, revisión de código y las funciones de Copilot CLI que usa este taller, así que puedes completar todos los ejercicios con él.

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> El agente en la nube está disponible en **Copilot Student, Pro, Pro+, Business y Enterprise**: todos los planes excepto Copilot Free. En Copilot Business o Enterprise, un administrador debe habilitarlo para tu organización.

> [!NOTE]
> MCP no se trata en este ejercicio. Para explorar el uso de servidores MCP con Copilot, consulta el [taller de CLI](../cli/) o el [taller de VS Code](../vscode/).
