Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software con escenarios realistas, una aplicación completa y un backlog compartido. Trabajarás de forma iterativa para planificar cambios, crear código, probar comportamientos, revisar pull requests y gestionar el trabajo con agentes.

## Escenario

Eres un desarrollador nuevo en Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de tablero con temática de desarrollo. El backlog de tu equipo ya está registrado como incidencias de GitHub, listas para que las recojas. Incluye trabajo de funcionalidad, como filtrado y paginación, junto con mejoras de calidad, como accesibilidad y estándares de codificación.

## Elige tu entorno

GitHub Copilot te acompaña donde trabajes. Elige el entorno que más se ajuste a la forma en que quieres crear. Cada taller empieza con su propia configuración y usa el mismo escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes en tu terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, Playwright MCP, Agent Merge y comandos de barra prácticos.

### [La aplicación GitHub Copilot][app]

Ejecuta sesiones paralelas de agentes, cambia de modo de sesión, colabora en lienzos y gestiona incidencias y pull requests de GitHub en la aplicación de escritorio.

### [Agente en la nube de GitHub Copilot][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa el progreso y revisa las pull requests que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
