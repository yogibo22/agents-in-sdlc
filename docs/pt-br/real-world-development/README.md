Explore o GitHub Copilot ao longo do ciclo de vida de desenvolvimento de software usando cenários realistas, um aplicativo completo e um backlog compartilhado. Você trabalhará de forma iterativa para planejar alterações, criar código, testar comportamentos, revisar pull requests e gerenciar o trabalho com agentes.

## Cenário

Você é um novo desenvolvedor da Tailspin Toys, uma empresa fictícia que oferece crowdfunding para jogos de tabuleiro com tema de desenvolvimento. O backlog da sua equipe já está registrado como issues do GitHub, pronto para você escolher. Ele inclui trabalhos de recursos, como filtragem e paginação, além de melhorias de qualidade, como acessibilidade e padrões de codificação.

## Escolha seu ambiente

O GitHub Copilot atende você em qualquer ambiente em que você trabalhe. Escolha o ambiente que combina com a forma como deseja criar. Cada workshop começa com sua própria configuração e usa o cenário compartilhado da Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use o assistente baseado em agente no seu terminal. Trabalhe com os modos Plan e Autopilot, instruções, skills, agentes personalizados, Playwright MCP, Agent Merge e comandos de barra práticos.

### [GitHub Copilot app][app]

Execute sessões paralelas de agente, alterne os modos de sessão, colabore em canvases e gerencie issues e pull requests do GitHub no aplicativo desktop.

### [GitHub Copilot cloud agent][cloud]

Atribua issues do GitHub a um agente assíncrono, oriente seu trabalho, acompanhe o progresso e revise os pull requests que ele abrir.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e no GitHub Codespaces. Trabalhe com o modo agente do Copilot Chat, servidores MCP e agentes personalizados sem sair do editor.
